About Paperwarden

        
      

      

        

          Paperwarden turns text into an encrypted QR code for printing. Use it
          for recovery codes, passwords, private keys, or other information you
          want to keep on paper.
        

        

          To recover a backup, you need its password and a copy of the app. A
          downloaded copy works offline, without this website or an account.
        

        
Plausible deniability

        

          One backup can hold up to four messages, each with its own password.
          Every backup has the same size and no visible message count. This
          offers limited plausible deniability: opening a later message reveals
          earlier occupied space, and a message's size can rule out room for
          more. It does not guarantee protection under coercion.
        

        
Using it safely

        

          Encryption and decryption run on your device. The app does not upload
          or automatically save your messages or passwords. Clear them when you
          finish.
        

        

          Paperwarden is a prototype and has not had an independent security
          audit. Use a trusted device and app; a compromised browser or extension
          can expose what you enter.
        

        

          How to use Paperwarden
          

            Enter a message and a long, unique password, then choose Create
            backup. Print at 100% with the QR's full white border. Check that you
            can recover every message from a photo of the actual print before
            storing it. Keep passwords separately; lost passwords cannot be reset.
          

          

            Download offline app saves a clean copy of Paperwarden, without your
            messages, passwords, or backups. Keep that file for recovery, and
            keep your printed or saved encrypted backups separately.
          

          

            Open the downloaded app in your browser and choose Decrypt. Scan the
            QR, choose a QR image, or use Paste backup for encrypted text or a
            complete backup link. Compare the six-word Backup ID with your paper,
            then enter the password for the message you want to open.
          

          

            A phone camera can open paperwarden.com from the QR. This uses the
            website's copy of the app. For recovery without the website, import
            the QR image or paste the link into your downloaded app.
          

        

        

          Verify your offline app
          

            Before opening a downloaded copy, compare its SHA-256 checksum with
            the checksum on GitHub (opens in a new tab).
            Use the file at the commit for the same build you downloaded; the
            displayed v0.1 alone does not identify a build.
          

          

            In the folder containing your download, run the command for your
            system. Use your actual filename if it differs.
          

          
macOS

          
shasum -a 256 paperwarden.html

          
Linux

          
sha256sum paperwarden.html

          
Windows PowerShell

          
Get-FileHash .\paperwarden.html -Algorithm SHA256

          

            All 64 characters must match; letter case does not matter. A match
            confirms the file matches that version, not that the software is
            free of flaws. See the
            verification guide (opens in a new tab)
            for choosing a trusted build and checking its signed attestation.
          

        

        

          Technical details
          

            Passwords use NFC normalization and Argon2id with 64 MiB of memory
            and three passes. HKDF-SHA256 derives separate keys, and AES-256-GCM
            authenticates each message before it is shown. Anyone holding the
            backup can attempt password guesses offline.
          

          

            Each PWN-1 envelope is exactly 2,858 bytes. The QR uses version 40
            and level L error correction. Up to four messages share the same
            space: one message can use 2,678 UTF-8 bytes, and each additional
            message costs 28 bytes of capacity. Unused space is filled with
            random data.
          

          

            Sharing space has privacy limits. Revealing a message's length and
            position can disclose earlier occupied space or rule out additional
            messages. This design has no formal deniability proof.
          

          

            The QR carries the encrypted backup after the # in its link. A
            normal page request excludes that fragment, but the page's code can
            read it. Importing a QR image or pasting a link into the app
            decodes it locally without contacting the encoded website.
          

          

            The printed backup includes encrypted text with line checksums and a
            full SHA-256 fingerprint to check copying errors. The six-word
            Backup ID is a public 64-bit shorthand for that fingerprint;
            matching words do not prove authenticity.
          

          

            Test the actual print and downloaded app on the devices you intend to
            use. Browser memory, screenshots, extensions, and operating-system
            records are outside the app's control; complete erasure cannot be
            guaranteed.
